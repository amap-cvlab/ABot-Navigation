# ABot-Navigation

Landing page and project websites for the ABot navigation model series.

## Structure

- `index.html` — Unified landing page with central N0 / N1 cards.
- `ABot-N0/` — ABot-N0 project website (original homepage).
- `ABot-N1/` — ABot-N1 project website (placeholder framework, content to be added).

## Access

- Direct sub-path access:
  - `/ABot-N0/index.html`
  - `/ABot-N1/index.html`
- Landing page with direct links:
  - `/index.html`

All pages are static HTML/CSS/JS and can be served directly (e.g., GitHub Pages).
